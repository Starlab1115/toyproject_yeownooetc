# 에어컨이 켜지면 문이 닫히는 하드웨어&소프트웨어
학교에서 에어컨을 틀었는데 문과 # 창문을 안닫고 다니는 친구가 있다.
에어컨을 틀었는데 문을 안닫으면 냉기가 다 빠져나가서 에어컨을 튼 이유가 사라진다.
그래서 이 문제를 해결하기 위해 에어컨이 켜지면 자동으로 문을 닫는 시스템을 만들었다.
자동문부터 보자면 이 자동문은 미디엄 모터 1개, 에어컨 버튼인 힘센서 1개 그리고 허브 1개가 있다.
힘센서를 누르면 에어컨이 켜지고 문이 자동으로 닫힌다. 문이 닫혀있는 경우에는 모터는 움직이지 않는다.
다음으로 에어컨 코드 같은 경우에는 1번 누름 에어컨이 켜짐, 2번 누름 온도가 0.5도씩 증가, 3번 누름 온도가 0.5도씩 감소, 4번 누름 바람세기가 1씩 증가, 5번 누름 바람세기가 1씩 감소, 6번 누름 에어컨이 종료가 된다.
이 시스템을 사용했을때 장점은 냉기가 빠져나가는 것을 막을 수 있고 교실 안이 문이 열려있을때 보다 더 빨리 시원해질 수 있다.
아쉬운점은 문이 열려있을때 계속 문을 닫아서 소음이 생길 수도 있고 학생들이 문을 세게 닫고 열었을때 모터가 고장날 가능성도 있다.
